
# Sistema de Gestión de Gimnasio

## Descripción

Sistema web destinado a la gestión de clases e inscripciones
de un gimnasio.

El sistema permitirá a los usuarios registrarse, iniciar sesión,
consultar las clases disponibles y gestionar sus inscripciones.

Los administradores podrán gestionar las clases, sus horarios
y los cupos disponibles.

## Objetivo

Facilitar la gestión de las clases del gimnasio y permitir que
los usuarios puedan consultar e inscribirse a las actividades
disponibles.

## Funcionalidades principales

### Usuarios

- Registro
- Inicio de sesión
- Visualización de clases
- Inscripción a clases
- Cancelación de inscripciones

## Requisitos
- Node,js (version 18 o superior)
- Navegador web
- Git

## Instalación y ejecución

1. Clonar el repositorio.
   Abrir una terminal y ejecutar: git clone https://github.com/reniturani/sistema-de-gimnasio.git
2. Abrir la carpeta del proyecto.
   En la terminal, con el comando: cd sistema-de-gimnasio
3. Instalar dependencias con npm install
   En la terminal, con el comando: npm install
4. Ejecutar el archivo.
   Abrir el archivo `index.html` en Visual Studio Code. Luego, hacer clic derecho sobre el archivo y seleccionar Open with Live Server para visualizar la aplicación en el navegador.
